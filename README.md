# Start with a Gun
Start each run with a gun or any item you want.

This mod detects at every run level whether you own a gun (or the item you specify in the config). If you don't have one, it will add it automatically.

If you're playing in multiplayer, only the host needs to have this mod enabled.

## Motivation
The game isn't well balanced for single-player mode, and it becomes frustrating when you don't randomly get any gun in the first shops. While this mod makes the game slightly easier, it makes the experience much more enjoyable. With just a simple handgun, the game doesn't become easy enough to make it boring.
